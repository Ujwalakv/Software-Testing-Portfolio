# DEF-002: Anyone can register as a teacher

| Field | Details |
|---|---|
| Module | Authentication / Access control |
| Test case | TC41 |
| Severity | High |
| Priority | High |
| Status | Open |
| Reported by | Ujwala K V |
| Date | 19-11-2026 |
| Environment | Windows 11, Chrome, Flask app on localhost:5000 |

## Steps to reproduce
1. Open the Sign up page.
2. Enter Name: Teach, Email: teach@test.com, Password: Passw0rd!
3. Choose Role: Teacher and click Create account.
4. Log in with these details and open Dashboard.

## Expected result
A visitor cannot give themselves teacher rights without approval.

## Actual result
The teacher account was created and the teacher dashboard opened. The user could create courses and add materials with no approval.
