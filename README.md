## Application Under Test
**LearnLoop** is a web-based Learning Management System where students enrol in courses, read study materials, generate AI-written notes, take quizzes and track their progress. Teachers create courses, upload materials and view student quiz results.

- **Application repository:** https://github.com/Ujwalakv/Gen-AI-LearnLoop-.git
- **Technology:** Python Flask, SQLite, HTML/CSS/JavaScript, Gemini API

### Modules tested
1. Authentication (registration, login, logout, roles)
2. Course management (listing, enrolment, teacher course creation)
3. Study materials
4. AI notes generation
5. Quiz system and scoring
6. Student dashboard
7. Teacher dashboard

## Objectives
- Prepare a test plan for the application.
- Design test cases using equivalence partitioning, boundary value analysis, decision tables and state transition testing.
- Execute the test cases and record actual results.
- Identify and document defects.
- Automate tests with Pytest and Selenium.
- Summarise the results and conclusions.
