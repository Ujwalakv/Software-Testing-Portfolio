# Software Testing Portfolio: LearnLoop (AI Learning Management System)

Application under test: see the project root README. Fill each folder as you test.

| Folder | What goes in it |
|---|---|
| 01_Test_Plan | Scope, objectives, resources, schedule, risks (template included) |
| 02_Test_Case_Design | Test cases using equivalence partitioning, BVA, decision tables |
| 03_Test_Execution | Actual results, pass/fail, date, tester |
| 04_Defect_Reports | One file per defect (template included) |
| 05_Test_Automation | Pytest suite lives in `../tests`; Selenium example here |
| 06_Test_Reports | Pytest output, summary and conclusions |
| 07_Screenshots | Evidence for executed cases and defects |

Generate evidence: `pytest -v > Software-Testing-Portfolio/06_Test_Reports/pytest_report.txt`
